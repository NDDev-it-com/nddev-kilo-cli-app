# NDDev Kilo Plugins

Use this focused skill when changing `xdg-config/kilo/nddev-builder-plugin.js`
or plugin config. Read `nddev-builder/references/plugins-hooks.md`.

The public plugin is local-only, import-free, and limited to deterministic
compaction context. Do not add permission, sandbox, auth, provider, network, MCP,
or marketplace behavior.
