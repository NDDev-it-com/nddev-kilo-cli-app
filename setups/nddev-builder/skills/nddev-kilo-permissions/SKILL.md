# NDDev Kilo Permissions

Use this focused skill for profile posture. Read
`nddev-builder/references/permissions-sandbox.md` before changing permission,
sandbox, launch argv, or guard behavior.

Full-auto is allow plus sandbox off plus `run --auto`. Safe is native ask/deny
plus sandbox on and network denied.
